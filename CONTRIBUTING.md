# Участие в разработке

Автор программы: @victoryur.

Для разработки нужны Windows x64, .NET SDK 10 и тестовый Linux-сервер. Сначала прочитайте [SECURITY.md](SECURITY.md) и [уточнённое ТЗ](docs/REQUIREMENTS.ru.md).

Изменение серверных команд должно включать проверку предусловий, верификацию результата и откат. Не добавляйте автоматический apply для новой комбинации ОС/init/firewall без отдельной VM-приёмки. Нельзя принимать неизвестные состояния как успех, отключать проверку host key или записывать секреты в диагностический вывод.

Перед предложением изменения выполните Release build и unit-тесты. Для изменений транзакции воспроизведите потерю соединения, отмену и срабатывание таймера на одноразовой VM. Для расширения SSH-транспорта выполните Docker integration. В описании изменений укажите реально выполненные проверки и непроверенные случаи.

Сохраняйте NuGet lock files. Обновление зависимости сопровождается проверкой advisories, лицензии и совместимости. Подпись поставки настраивается сертификатом автора; сертификаты, приватные ключи и токены не коммитятся.

Не публикуйте адреса реальных серверов, пароли, ключи и полный вывод пользовательских конфигов в issues. Для уязвимостей следуйте SECURITY.md.
